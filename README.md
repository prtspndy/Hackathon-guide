# Hackathon Guide

This repository is a clean, easy-to-scan record of the hackathons I have participated in and the projects I explored during each one. It is organized to make the journey easy to follow from the first challenge to the final prototype.

## Overview

The goal of this repo is simple: capture the learning path across multiple hackathons, highlight the ideas that were attempted, and keep each event organized in one place.

## Repository structure

- `hackathons/` contains the detailed notes for each event.
- Each file captures the event theme, time constraints, and project directions.
- This repo can be expanded as new hackathons and projects are added.

## Suggested use

1. Start with the event that matches your interest.
2. Review the project concept and time limit.
3. Use the notes as inspiration for prototypes, product ideas, or future builds.

## Notes

This project is intentionally lightweight and README-first so it stays easy to navigate while also being easy to expand over time.
